Context-aware applications, including those powered by large language models, rely on retrieving semantically relevant information rather than exact keyword matches. This session shows how to build such applications in Java by generating vector embeddings and using Redis as a vector database to perform similarity searches, enabling features like semantic search and retrieval-augmented generation.
