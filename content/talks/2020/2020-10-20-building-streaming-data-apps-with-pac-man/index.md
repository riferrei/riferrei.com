In this near-zero-slides talk, the classic Pac-Man game becomes a way to generate events that drive a streaming data application. As the audience plays, a live scoreboard is built from scratch using ksqlDB, the streaming database for Apache Kafka, and the generated data is then sent to Elasticsearch and Kibana where the real action happens.
