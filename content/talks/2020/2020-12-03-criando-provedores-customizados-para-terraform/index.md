O Terraform permite descrever e provisionar infraestrutura como código, mas nem toda API ou serviço possui um provider pronto para uso. Esta sessão mostra como escrever um provider customizado para o Terraform em Go, cobrindo a estrutura de um plugin, a definição de recursos e schemas, o ciclo de vida de create, read, update e delete, e como testar e distribuir o provider para que qualquer serviço possa ser gerenciado de forma declarativa.
