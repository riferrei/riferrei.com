Observabilidade permite entender o comportamento interno de aplicações distribuídas a partir dos sinais que elas emitem. Esta sessão mostra como usar o Elastic APM para instrumentar serviços, coletar traces, métricas e erros, e correlacionar esses dados no Elastic Stack para diagnosticar problemas de desempenho e latência em produção.
