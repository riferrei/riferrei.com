Pac-Man has been a beacon of fun and joy for people of all ages since its '80s release, but few realize it can also illustrate event streaming concepts. In this near-zero-slides talk, the game is deployed to a cloud provider directly from a GitHub repository and the audience plays to generate events; during gameplay a scoreboard is built from scratch using ksqlDB, an event streaming technology built out of Kafka Streams, and a serverless API then monitors the aggregated game statistics in near real time to reveal the most skilled Pac-Man player present.
