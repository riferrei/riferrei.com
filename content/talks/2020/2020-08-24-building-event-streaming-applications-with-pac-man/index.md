Learning event streaming is a lot easier when it is fun. This session builds a streaming application around the classic Pac-Man game, capturing gameplay events into Apache Kafka topics and using ksqlDB to process them in real time, powering a live scoreboard that aggregates player metrics such as highest score, level reached, and losses as events arrive.
