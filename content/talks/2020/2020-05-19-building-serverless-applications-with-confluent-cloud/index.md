Serverless architectures and event streaming are a natural fit: functions react to events while the platform handles scaling and operations. This session shows how to build serverless applications backed by Confluent Cloud, wiring managed Kafka to serverless compute so developers can create responsive, event-driven systems without provisioning or maintaining messaging infrastructure.
