Event streaming has reshaped how organizations move and process data in real time, but designing these architectures well requires more than just adopting a message broker. This talk shares practical best practices for building streaming data architectures with Apache Kafka, covering topic and schema design, data contracts, stream processing patterns, scalability, and the trade-offs involved in evolving from batch to real-time systems.
