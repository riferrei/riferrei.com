A story-driven session that combines Apache Pulsar and the Elastic Stack to build a real-time streaming analytics pipeline. The talk shows how Pulsar ingests and processes high-volume event streams and how that data can be indexed and visualized in Elasticsearch and Kibana to deliver actionable insights with low latency.
