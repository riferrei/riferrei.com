Event streaming systems built on technologies like Apache Kafka are inherently distributed and asynchronous, which makes understanding their behavior in production a real challenge. This session shows how to instrument streaming applications with Elastic APM and distributed tracing so that events can be followed as they flow across producers, brokers, and consumers, giving teams the visibility they need to diagnose latency and failures in real time.
