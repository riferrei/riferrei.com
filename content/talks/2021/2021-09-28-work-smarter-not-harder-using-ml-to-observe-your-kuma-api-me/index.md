Service meshes like Kuma expose a wealth of metrics about API traffic, but manually watching dashboards and setting static thresholds does not scale as systems grow. This talk shows how machine learning can be applied to the metrics emitted by Kuma to automatically detect anomalies and surface meaningful signals, helping teams observe the health of their APIs more intelligently and react before issues impact users.
