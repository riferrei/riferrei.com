O Elastic Stack é capaz de trazer grandes benefícios para adeptos e praticantes de engenharia de dados, ainda que seu uso nem sempre seja óbvio, já que muitos acreditam que a plataforma serve apenas para agregar logs. Esta sessão apresenta uma introdução ao Elastic Stack e mostra como ele pode resolver problemas clássicos de engenharia de dados, abordando integração e reconciliação de dados, técnicas de filtragem, agregação e curadoria, além de mecanismos de consolidação de dados para fins analíticos.
