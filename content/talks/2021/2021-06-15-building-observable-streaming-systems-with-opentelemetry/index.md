Streaming systems built on technologies like Apache Kafka are inherently distributed and asynchronous, which makes understanding their behavior a challenge. This session shows how to make streaming systems observable using OpenTelemetry, propagating context across producers and consumers to capture distributed traces and metrics that reveal end-to-end data flow and latency.
