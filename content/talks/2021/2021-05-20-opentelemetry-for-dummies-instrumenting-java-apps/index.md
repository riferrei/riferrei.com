Tracing has become one of the key dimensions of building observability stacks, and OpenTelemetry has emerged as the standard that lets developers collect telemetry in a technology-agnostic way. This talk explains, in a for-the-rest-of-us style, how to instrument Java applications with OpenTelemetry—including how the Java agent can automatically instrument the JVM with additional bytecode—and how to send the resulting traces and metrics to a backend using a collector.
