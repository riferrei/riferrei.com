Apache Kafka Connect provides a framework for streaming data between Kafka and external systems, and while many connectors exist, teams often need to build their own for custom sources and sinks. This hands-on workshop teaches how to develop a custom Apache Kafka connector and deploy it on AWS, following the right best practices for building reusable, production-ready connectors.
