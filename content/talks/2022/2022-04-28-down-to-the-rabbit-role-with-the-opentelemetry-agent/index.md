Instrumenting code by hand is not always practical, which is where the OpenTelemetry agent and auto-instrumentation come in. This session follows the rabbit hole of how the agent attaches to running applications to capture traces and metrics with little or no code changes, what it can and cannot see automatically, and how SREs can use it to gain observability into services they do not own.
