As AI agents grow more capable, how they remember becomes as important as how they reason. This talk examines memory design for agentic systems, arguing that a well-designed single-layer memory can outperform more elaborate schemes, and explores practical trade-offs in giving agents durable, relevant context without unnecessary complexity.
