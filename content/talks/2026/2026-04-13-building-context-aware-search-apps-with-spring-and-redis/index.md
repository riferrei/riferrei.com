This workshop teaches developers how to build applications capable of handling searches that account for user intent, using hybrid search that blends full-text search with vector similarity to improve how users find information. Through hands-on exercises, participants learn to load a dataset into Redis, generate embeddings, model the domain with Spring Data, implement hybrid queries, and monitor Redis for optimizations, connecting these concepts to the recommendation systems behind services like Amazon and Netflix.
