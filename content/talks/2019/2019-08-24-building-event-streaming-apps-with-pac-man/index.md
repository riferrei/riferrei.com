Pac-Man has been a beacon of fun for people of all ages since the '80s, but few realize it can also teach event streaming. In this near-zero-slides talk, the game is deployed to a cloud provider straight from a GitHub repository, the audience plays to generate a stream of events, and a live scoreboard is built from scratch with ksqlDB on top of Kafka Streams, with a serverless API monitoring the aggregated stats in near real time to crown the most skilled player in the room.
