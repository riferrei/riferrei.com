Building applications on top of Apache Kafka no longer requires standing up and operating your own clusters. This session shows how to design cloud-native, event-driven applications backed by Confluent Cloud, a fully managed Kafka service, covering how to connect producers and consumers, offload operational burden to the platform, and scale elastically so developers can focus on business logic rather than infrastructure.
