Learning event streaming is far more fun when the demo is a game everyone recognizes. Using a playable Pac-Man built on Apache Kafka, this session shows how player events flow through topics, get processed with stream processing, and feed a real-time scoreboard, turning abstract streaming concepts into something you can see and interact with.
