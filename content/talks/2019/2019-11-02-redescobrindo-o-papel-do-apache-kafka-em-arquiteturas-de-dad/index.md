Muito além de uma simples fila de mensagens, o Apache Kafka se tornou a espinha dorsal de arquiteturas de dados modernas. Esta apresentação revisita o papel do Kafka como plataforma de streaming de eventos, mostrando como ele viabiliza integração de dados, processamento em tempo real e desacoplamento entre serviços em sistemas distribuídos.
