Arquiteturas de dados modernas trocam o controle centralizado por sistemas distribuídos e orientados a eventos, o que exige novos padrões de projeto. Esta sessão apresenta design patterns de Apache Kafka para desacoplar serviços, processar fluxos de dados em tempo real e integrar plataformas de Big Data, mostrando como abraçar essa 'anarquia' de forma organizada e escalável.
