Running Apache Kafka in the cloud changes how developers design, deploy, and operate event streaming applications. This talk covers the tips, tricks, and architectural practices that let Java and other developers be productive with Kafka as a managed cloud service, avoiding common pitfalls around connectivity, scaling, and cost.
