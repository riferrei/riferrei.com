An honest, myth-busting tour through Apache Kafka that answers the questions developers often hesitate to raise. The talk clarifies how Kafka really works under the hood, from the commit log and partitioning to delivery guarantees and consumer offsets, so attendees leave with a solid mental model and the confidence to build event streaming applications correctly.
