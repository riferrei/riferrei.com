Running Apache Kafka in production on Kubernetes introduces operational challenges around stateful workloads, storage, scaling, and lifecycle management. This talk explores how the Confluent Operator automates the deployment and day-two operations of Kafka and the broader Confluent Platform on Kubernetes, covering configuration, scaling, and best practices for running a resilient cluster.
