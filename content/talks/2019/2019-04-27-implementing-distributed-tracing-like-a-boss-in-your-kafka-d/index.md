Because Kafka producers and consumers are decoupled and unaware of each other, understanding how a single request flows across an event-driven system can be surprisingly hard. This talk shows how to instrument Kafka-based applications with distributed tracing, propagating context through producers, brokers, and consumers so you can visualize dataflows end to end, pinpoint latency, and debug production issues with confidence.
