Streaming data pipelines let applications react to events as they happen instead of waiting for batch jobs to run. This session shows how to build an end-to-end pipeline on Apache Kafka, using Kafka Streams to transform and enrich events in code and KSQL to express the same stream processing declaratively with SQL-like queries.
