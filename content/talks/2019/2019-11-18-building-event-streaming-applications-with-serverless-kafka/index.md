Event streaming is at the heart of modern cloud-native systems, but operating Kafka clusters can distract teams from building features. This session explores how a serverless approach to Kafka lets developers build event streaming applications without managing brokers, using fully managed infrastructure that scales on demand, and how this model fits naturally into Kubernetes and cloud-native architectures.
