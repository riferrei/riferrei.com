title: Open Source
---

I contribute to [LangChain4j](https://github.com/langchain4j/langchain4j), an idiomatic open source Java library for building LLM-powered applications on the JVM. Recent work includes adding native vector search embedding stores so developers can build RAG, recommendation engines, and AI memory systems.

I also ported [RedisVL to Go](https://github.com/redis/redis-vl-golang), an open source, AI-native client that brings vector search, semantic caching, LLM memory, semantic routing, rerankers, and an MCP server to the Redis ecosystem for Golang developers.
